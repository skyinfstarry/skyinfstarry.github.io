五、隐私与个人信息保护

本站极度重视您的隐私与个人信息保护。 有关本站如何收集、使用、存储、保护您的个人信息以及您享有的权利， 请详细阅读《隐私政策》（可在本站页脚或相关页面查阅）。

以下为本协议中关于隐私的核心要点，完整内容以《隐私政策》为准：

  • 本站整体托管于 GitHub Pages（境外服务器），您访问本站任何页面时，GitHub 均会自动记录您的 IP 地址、访问时间等必要的网络日志信息（详见第八节）；
  • 绝大部分工具（包括 AES 加密、Base64 编解码、文本差异对比、颜色浏览器、计算器等）均完全在您的浏览器本地运行，代码与数据不离开您的设备；
  • 「意见反馈」通过第三方服务（Supabase）提交，该服务节点位于境外。为防止滥用，本功能会在您的浏览器本地生成一个随机设备标识（与您的真实身份无关，仅用于每日提交条数限制，清除浏览器本地数据即可删除其本地副本），连同您填写的反馈类型、标题、内容以及选填的联系方式一并提交并存储于境外服务器。请勿在反馈中填写敏感个人信息；
  • 「C 语言在线编译」工具需要将您输入的代码与标准输入内容发送至境外编译服务（Wandbox）方可完成编译与运行，请勿在其中填写密码、密钥等敏感信息（详见第八节）；
  • 本站部分页面使用不蒜子（busuanzi）统计访问量，该服务会在您访问时收集您的 IP 地址、所访问页面地址等必要计数信息；
  • 您有权通过本站「意见反馈」页面申请查询、更正、删除您的反馈记录，或撤回相关同意；
  • 本站不会主动收集您的姓名、手机号、身份证号等敏感个人信息。

⚠️ 境外存储提示：本站「意见反馈」功能使用了 Supabase 服务，其服务器位于境外。 当您提交反馈时，您所填写的内容将被传输并存储于境外服务器。请您在提交前确认该等传输符合您所在法域的要求， 并避免在反馈中填写任何敏感个人信息。

八、第三方链接与服务

本站部分功能依赖下列第三方服务。您使用相应功能时，相关数据将按下述方式处理，具体规则以各服务官方政策为准：

  • GitHub Pages（境外托管）：本站全部页面托管于 GitHub Pages，您访问本站时，GitHub 会自动收集您的 IP 地址、访问时间等日志信息以完成内容传输；
  • jsDelivr（CDN，境外）：用于加速加载部分页面的开源脚本与样式文件，访问时其会获得您的 IP 地址等网络连接信息；
  • Supabase（境外）：用于「意见反馈」的提交与存储，处理的信息种类详见第五节；
  • Wandbox（境外）：用于「C 语言在线编译」工具，您输入的代码与标准输入内容将被发送至该服务完成编译和运行；本站已将该请求设置为不公开保存，仍请您避免在其中输入敏感信息；
  • 不蒜子（busuanzi）：用于页面访问量统计，会收集您的 IP 地址与所访问页面地址等必要信息；
  • Google Fonts（境外）：部分页面加载在线字体时，Google 会收到您的 IP 地址等连接信息；
  • 其他外部链接（如 GitHub、百度、Wikipedia 等）：仅为方便您而提供，本站无法控制第三方网站的内容、隐私政策或行为。
